# 轻松翻译 1.1

首页底部新增“额外内容”，与目标语言、上下文并列，点击向上展开菜单。

- 总开关关闭时只请求译文，不再发起第二次补充请求；之前勾选的项目会保留。
- 可分别选择注音与读音、词汇辨析、搭配与语法、纠错解析、补充说明、表达评价、表达建议。
- 全部取消勾选时，同样只发出一次译文请求。开启并勾选额外内容时，仍通过两个并行请求优先显示译文。
- 选项按预设独立保存，立即生效、自动保存，重启后恢复；设置页同步提供相同选项。
- 提示词与输出结构只包含已选内容。模型额外返回的未选内容会在保存和展示前过滤；关闭注音后，不显示缺少注音的提示。
- 已有历史沿用当时的请求选项；重新翻译采用预设当前的选项。旧版三个输出开关会自动兼容，原有注音偏好保持不变。

版本为 `1.1.0`，内部版本号为 `10`。沿用包标识及正式签名，可覆盖升级 1.0.0 并保留预设、草稿和历史。

本次新增 10 项核心测试和 3 项 Android 检查，验证实际请求数量、所选输出结构、返回内容过滤、旧数据兼容、按预设保存、重启恢复及底部菜单布局。完整结果见 [验证摘要](../artifacts/v1.1.0/verification.json)。
