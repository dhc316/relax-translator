# 轻松翻译开发与验证

工程使用 Kotlin 2.1.20、Jetpack Compose、Android Gradle Plugin 8.9.2 和 Gradle 8.11.1，编译与目标 SDK 为 35，最低 Android API 为 26。网络层使用 OkHttp，历史与配置通过本机原子 JSON 文件保存，密钥使用 Android Keystore AES GCM 加密。

## 目录与构建

源码位于 `android/app/src/main`。`Core.kt` 定义数据、上下文筛选、提示词和响应解析；`Learning.kt` 定义按翻译方向生成的词汇、读音和纠错结构；`Detail.kt` 实现独立详情页与输入上浮；`Glass.kt` 采样实际内容生成顶部背景模糊；`AppViewModel.kt` 管理交互状态、请求快照和保存队列；`Storage.kt` 管理原子存储、图片和密钥。

所有项目专用构建工具位于 `.local/`，不会向工作目录根部散放工程文件。`tools/bootstrap.py` 下载并校验 Gradle 和 Android 命令行工具，`tools/setup-sdk.ps1` 安装 SDK 组件。JDK 使用电脑已有的版本，要求 JDK 17 或更新版本；当前机器使用 JDK 21。

在项目根目录运行：

```powershell
# 首次准备环境
.\tools\setup-sdk.ps1

# 调试 APK 和核心单元测试
.\build.ps1

# Android 界面与集成测试，需要已启动的模拟器
.\build.ps1 -Tasks @('connectedDebugAndroidTest')

# 静态检查和正式 APK
.\build.ps1 -Tasks @('lintDebug', 'assembleRelease')
```

正式包读取 `.local/signing/signing.properties` 中的本机签名配置。签名密钥保存在 `.local/signing/release.jks`，未放入 APK、源码压缩包或版本控制。后续升级同一应用需继续使用此密钥。

Windows 的 Java 启动参数文件需要与本机原生编码一致，因此 Gradle 守护进程使用 GBK，Java 源文件和测试进程使用 UTF 8。构建固定使用工程的完整路径并关闭 Gradle 文件监视；正式包构建还会强制重新执行任务、禁用构建缓存并使用单次进程，避免 Windows 路径与缓存导致旧 APK。SDK 原生工具使用同一目录的短路径。

## 自动验证

58 项核心单元测试覆盖：上下文关闭、会话隔离、时间边界、条数与时间的交集、历史容量截断、图片历史文字化、保存恢复、接口地址检查、多模态请求、可选接口参数、原文与历史作为数据、结构化回复与回退、截断和空回复、本地 HTTP 往返、鉴权错误脱敏及取消请求；另外验证双向词汇差异、读音、纠错、结构化存储、旧记录兼容，以及解析字段异常时保留有效译文。

22 项 Android 流程与渲染测试覆盖：

- 首页、三个向上菜单、常用语言编辑、侧栏及模型设置窗口。
- 滑动进入空预设、卡片内设置保存、草稿保留及重新打开后恢复。
- 历史只显示两段摘要，点击进入详情、复制、返回设置及删除单条记录。
- 图片导入和压缩，经本地 HTTP 接口发送图片及筛选后的上下文；发送期间切换语言后保留原请求配置；密钥加密与恢复。
- 中译英多个词汇的用法与例句。
- 实际弹出系统输入法后，首页和详情输入区域位于键盘上方。
- 预设堆叠切换过程的触摸和中间帧；在左右实际重叠区域点击，验证左卡覆盖当前卡、当前卡覆盖右卡，以及最左卡保持最高层；前景左卡仅覆盖约 12dp 边缘，右侧多卡片紧密收拢在后。
- 原文输入与译文在最上方，双方注音紧接其后，并先于其他解析；日语保留假名及罗马字，无错误时不生成纠错卡片。
- 采样滚动历史得到实际背景模糊，旧系统的软件模糊已生成有效位图。
- 输入卡片从首页位置向上移动，并停在详情顶部栏下方。

界面测试截图由 Android 原生截图接口采集。0.3.0 的正式包流程保存在 `tools/smoke-v03.py`；0.3.1 使用 `tools/smoke-v031.py` 检查正式签名 APK 的原文、译文、注音排序、日语形式、实际键盘和卡片重叠点击，可通过 `--upgrade` 检查 0.3.0 覆盖升级后保留预设与历史。脚本限制只操作项目自己的模拟器。

各支持版本均将实际顶部内容采样为独立位图，再进行软件模糊；正文正常绘制，避免共享实时图层造成部分 GPU 的投影与圆角错误。模糊下边缘渐隐，标题和按钮保持清晰。键盘适配使用 IME Insets、可调整的卡片高度和 BringIntoView。

本次通过数量、安装检查和 APK 校验值见 `artifacts/v0.6.0/verification.json` 及同目录检查记录。历史版本与完整日志保留在开发机器，本仓库提供当前版本的验证摘要。

## 运行边界

本次接口验证使用本机 MockWebServer，未请求任何用户的远程模型账号。API 兼容性和实际翻译质量需要用户选定供应商后使用自己的配置验收。

历史导出不包含密钥或图片文件。模型服务端对请求的保存方式由服务提供方决定；本项目的上下文时间设置控制发送的历史范围。

## 0.3 回归重点

`ResponseParser.kt` 处理常见回复结构与截断恢复；`Readings.kt` 保存双向注音及日语假名、罗马字；`Speech.kt` 调用系统文字转语音；`PresetContexts.kt` 按预设归拢旧历史及筛选独立上下文。存储版本为 3，旧会话字段保留兼容读取，不再是用户侧独立入口。

新增验证包括截图中的截断回复、二次编码、嵌套与字段别名、两份日语读音持久化、无错误时隐藏纠错、跨旧会话的预设隔离、草稿恢复和归档预设迁移。界面测试还直接在 Android 的 JSON 实现上恢复截断回复并显示历史卡片，验证发送中切换预设、删除发送中的预设，以及自动保存后重启。

朗读功能需要手机安装对应系统语音服务与语言包；参考 [Android TextToSpeech 文档](https://developer.android.com/reference/android/speech/tts/TextToSpeech)。模拟器检查覆盖朗读入口，不代替用户真机的语音包和声音质量验收。

## 0.4 并行请求回归

`ParallelTranslation.kt` 使用独立协程同时启动 A 纯译文请求和 B 完整解析请求，分支失败相互隔离。收到 A 即通过回调更新界面并落盘，B 返回后更新相同记录 ID；B 先完成则取消仍在进行的 A。请求共享已固定的输入、图片、模型和上下文。

9 项新增核心测试通过本机 MockWebServer 验证两个请求先同时到达、A 的中间结果可在 B 被阻塞时发布，以及先后颠倒、分支失败、双失败脱敏、取消与中断恢复。2 项新增 Android 流程测试实际阻塞 B，检查 A 已显示可复制、切换预设后继续补充到同一条历史，及取消和删除不会被晚到结果覆盖。

正式包检查使用 `tools/smoke-v04.py`，可通过 `--upgrade` 检查 0.3.1 覆盖升级；脚本仅允许项目自己的模拟器。真实翻译会发送两个请求，接口用量也按两次计算。模拟器及本机兼容服务不使用用户的外部模型账户。

## 0.5 动画与图库回归

HomeScreen 统一维护卡片进度，完整预绘相邻草稿和按钮。标题、历史、语言和上下文使用同一进度先淡出再淡入，避免两组文字重叠；图片区采用全卡片一致高度。历史占满背景并在浮动输入卡片后方渐隐。

顶部不再在每次滚动时取消并延迟采样，而是使用合并的连续帧流。ProgressiveBlur.kt 的行半径线性降低到零，通过前缀和作三次横纵平滑，不产生固定模糊分段；首帧有渐变遮罩，背景位图更新时标题始终独立清晰。

新增 3 项核心像素测试验证对比度从模糊区向清晰区恢复、底部像素保真、均匀色无暗边及小图。新增 4 项原生流程测试验证首页编辑删除和最后预设保护、滑动结束之前历史已过渡、带图前后高度一致、滚动中模糊更新及图库选择与取消协议。

图库优先使用系统 Photo Picker；不支持时调用 ACTION_PICK 图库，极少数未安装图库的旧系统保留 GET_CONTENT 兼容入口。选择的图片直接复制到私有存储，不需长期 URI 权限。参考 [Android Photo Picker 文档](https://developer.android.com/reference/androidx/activity/result/contract/ActivityResultContracts.PickVisualMedia)。正式包使用 smoke-v05.py、smoke-v05-polish.py 和 smoke-v05-parallel.py 检查安装、图库、动画和双请求。

Android 11 模拟器自带 Google 相册 4.52 已提示版本停用，图库兼容检查改用仅安装于项目模拟器的 [Fossify Gallery 1.14.2](https://github.com/FossifyOrg/Gallery/releases/tag/1.14.2)。测试 APK 从官方发布页下载，SHA256 为 `879e8b2bb80930bf6d58ff88684cd692953db51017d5441f3fea2d6e46e33724`；仅保存在 `.local/qa-apps/`，不打包到译间 APK 或源码压缩包。Android 15 使用系统 Photo Picker。

模糊的图形层在 GPU 端先缩到最多 320 像素宽，再读取位图并按相同比例调整半径，避免旧系统每一帧搬运整张高分辨率背景。画面仍按原尺寸绘制，渐变范围与实际模糊半径保持一致。

## 0.5.1 顶部显示回归

标题栏通过实际高度限定模糊范围；副标题显式行高、随字号撑开，淡出中点仍保留最小行高。取消顶部重色罩与模糊位图淡入叠加，下边缘只在标题栏内部做 12dp 接缝过渡。下方历史标题完全在覆盖范围之外。详情结果内容变化也触发背景更新。

0.5.1 最终使用单个不裁切的绘制层承载正文，该层按标题栏的尺寸确定采样边界，直接显示正文并读取标题栏位图；在 CPU 端缩到最多 320 像素宽做线性渐变模糊，替代先前正文重复绘制、另记录一个缩小图层的路径。发布前检查所有采样像素的透明度，拒绝空白或部分透明的帧。底部条纹对比度检查同时确保正文仍然完整绘制到采样范围外。

新增 2 项实际首页回归检查正常与 1.6 倍字号的文本行框、模糊边界与历史标题位置，另新增 1 项独立渲染检查：在黑白条纹上测量顶部与底部的对比度、区域平均亮度及下方原始内容，排除不模糊、色罩太白、下边缘不清晰三类问题。再新增 1 项反复进入详情、返回首页、切换预设后完整采样与滚动更新的回归。原有滚动中帧更新测试继续保留。正式包使用 `tools/smoke-v051.py` 验证 0.5.0 覆盖升级、详情排序、真实键盘、卡片点击与滚动录屏。
