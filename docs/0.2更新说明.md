# 轻松翻译 0.2 更新说明

本次按用户的四张使用反馈截图调整页面结构、动画、键盘和语言学习内容。反馈原图保存在 `references/feedback-0.2/`。

首页历史卡片只保留原文和译文，点击进入详情页。发送新输入时，卡片上浮到屏幕顶部的设置栏下方；原文和译文合并在一张卡片中，下方分别显示读音、纠错、词汇辨析和其他说明。浏览历史不会改变首页当前的预设和临时语言选择，返回历史不会重复请求模型。

顶部采用真实背景模糊，滚动到栏下方的内容会被模糊，文字按钮保持清晰。预设卡片切换时有位移、缩放、倾斜以及后方卡片的跟随动作。

首页和详情页都会避让实际弹出的输入法，并将输入区域带到可见位置。详情原文可直接编辑后重新翻译。

中译外的提示词要求为关键词提供多个外语对应词，说明语义差异、场景、搭配、例句和中文释义；外译中要求输出原文读音、用法和具体纠错，没有明显错误时如实说明。数据结构新增可选 learning 对象，旧记录继续可读；旧记录不会自动补生成新解析，可在详情页重新翻译。

安装包沿用 0.1.0 的应用标识和签名，版本号增加为 0.2.0。远程模型仍使用用户自己的接口配置。
