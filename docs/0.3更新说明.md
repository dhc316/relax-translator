# 轻松翻译 0.3 更新说明

本次按用户的四张新反馈图修改，原图保存于 `references/feedback-0.3/`。

## 双向注音与读音

翻译详情最上方显示原文、译文两份注音及朗读入口。中文使用带声调拼音，英语要求 IPA，日语要求分别返回假名与罗马字。注音独立于词汇解析开关；关闭词汇模块仍会请求双向注音。

朗读使用手机的系统文字转语音服务，可播放原文、译文或停止播放。系统没有对应语音服务或语言包时会说明原因，不把未发声当作播放成功。本地演示新增“日语注音示例”，完整展示中文拼音、日语假名和罗马字。旧记录未包含的注音需重新翻译补充。

纠错只在模型明确标记有错，或返回有效的原片段与不同的修正片段时显示。仅返回“没有明显错误”的总结不会生成纠错卡片。

## 回复兼容

增加对截断 JSON、代码块、思考标签、二次编码、嵌套结果、常见字段别名和内容数组的处理。优先恢复完整译文字段，读取不到有效译文时给出重试提示，避免整段结构数据占据译文区。达到长度限制或丢失解析时会说明情况。

提示词要求先输出译文和双向读音，再输出词汇解析，限制词汇展开数量。新模型的默认最大输出长度调整为 8192；已有模型的用户设置继续保留。旧历史中误存的 JSON 在读取时尝试恢复。

## 预设与独立上下文

预设合并原来的独立会话入口。每张卡片有自己的历史、上下文范围和草稿；切换预设不会携带其他预设的内容。旧会话按每条记录保存的预设归拢，已删除的旧预设有历史时恢复为归档预设，方便继续查看。

目标语言、模型、上下文、输出选项、预设名称及补充要求自动保存。顶部加号与侧栏用于创建预设，不再单独新建会话。新卡片点击“设置这个预设”创建后即可直接修改，关闭编辑窗口也会保留改动。删除预设会一并删除它的历史、上下文和草稿，操作前有确认说明。

## 卡片、模糊与阴影

输入卡片宽度调整为屏幕的约 84%，两侧显示真实相邻预设。卡片位置、缩放、前后层级与滑动共用同一个进度，采用手机后台式横向堆叠，移除原来向上垫出的装饰卡片。

顶部模糊改为独立位图采样，与正文绘制分开，避免共享实时图层导致下方内容和圆角异常。模糊下边缘渐隐。弹窗及圆形按钮使用较淡的形状阴影，并预留绘制边距，避免大块投影和截边。

接口验证仍使用项目自己的本地兼容服务，不使用用户的外部模型账号。真实模型的输出质量和语音包可用性需在用户自己的配置与手机上验收。
