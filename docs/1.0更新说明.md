# 轻松翻译 1.0

轻松翻译首个 1.0 正式版本：输入文字或选择图片，快速获取译文，再查看原文与译文的读音、词义、用法和建议。

- 版本号统一为 `1.0.0`，Android 内部版本号为 `9`；应用设置页、正式 APK、源码包、验证记录与 GitHub Release 使用相同版本。
- 译文与完整解析并行请求，译文先返回就先显示；日语支持假名和罗马字，纠错内容只在模型报告错误时显示。
- 预设自动保存，分别保留模型、目标语言、输入草稿、历史和上下文；支持按条数、时间或两者共同限制上下文。
- 沿用雾蓝淡紫的翻译图标、轻量标题字体、图库入口、卡片切换与键盘避让。
- 同步并保留 GitHub 上最新的 README 功能简介与措辞修改，仓库已公开为 `dhc316/relax-translator`。

包标识 `com.yijian.translate` 与正式签名保持一致，可覆盖安装 0.6.0 并保留已有数据。历史发布版仍保留在 GitHub Releases 中，最新下载指向 1.0.0。

本版重新执行核心测试、Android 流程检查与正式包覆盖升级验证，结果见 [验证摘要](../artifacts/v1.0.0/verification.json)。真实翻译需要用户自行配置兼容的模型接口与密钥；内置示例不请求远程模型。
