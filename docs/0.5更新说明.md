# 轻松翻译 0.5 更新说明

## 连贯切换

相邻卡片提前渲染完整草稿、图片、模型和操作按钮，移除滑动时的简化预览。滑动中不替换输入控件，手势完成后才提交预设归属。继续使用左卡在前、选中卡居中、右卡密集收拢在后的方向，左侧只覆盖少量边缘。

标题、历史区和底部语言、上下文选项共用卡片的连续进度，采用淡出、轻移、淡入的过渡，避免突然换内容或两组文字叠在一起。带图片与不带图片的预设使用统一高度，添加或移除图片时平滑改变高度。

历史滚动区域扩展到输入卡片后方，与输入区共用雾蓝背景，在靠近卡片处渐隐。输入卡片用更宽的浅阴影和细边框浮起，取消矩形截断形成的分区感。

## 连续渐变模糊

顶部的真实背景模糊从上到下逐行线性减小半径，最下方恢复清晰。加大顶部最大半径，并延长自然衰减区域；标题和按钮独立保持清晰。

采样改为合并的连续帧流，在滚动和左右切换期间更新，不再等待手势停止后才补一张模糊图。首帧已有渐变遮罩，第一份背景到达时平滑显现，避免先清晰后突然变化。

## 图库与预设管理

“附带图片”优先打开系统照片选择器，较旧系统直接进入图库选择图片，导入后继续按原有逻辑校正方向、压缩并保存到应用内部。

卡片右上角编辑窗口新增“删除预设”，确认后删除该预设的历史、上下文和草稿；最后一个预设保留保护。移除首页顶部菜单左侧的加号。新预设仍可通过末尾空卡片或侧栏创建。

## 回归

58 项核心测试、18 项 Android 流程测试，包含中间帧的历史变化、图片卡片前后高度一致、重叠点击、编辑删除、滚动未结束时模糊已经更新，以及图库选择和取消。原有双请求并行、双向注音、键盘避让与独立预设数据继续保留并验证。
