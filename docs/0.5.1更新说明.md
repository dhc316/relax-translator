# 轻松翻译 0.5.1 顶部显示修复

用户反馈指出 0.5.0 首页副标题裁切、历史标题异常模糊，以及标题栏背景被浅色遮罩盖平。原有测试只检查产生了模糊位图、滚动时有更新，未检查模糊边界和最终对比度，验收不足。

副标题现在明确设置行高，移除固定高度裁切，并随字号增加实际标题栏高度。卡片切换到淡出中点时仍为副标题保留完整行高，避免标题栏收缩。

背景模糊止于标题栏底部，按标题栏实测高度布局，静止时不会覆盖下方的“历史记录”和条数。顶部文字及按钮在独立清晰层绘制。真正滚到标题栏后面的历史内容由上到下逐行减小模糊半径，底部接回实时正文；没有内容滚入时，标题栏后方只有原有雾蓝背景。

移除原来最上方 62% 不透明度的色罩，换成很轻的调色；模糊位图直接替换对应背景，不再将清晰文字与模糊文字淡入叠加。下边缘的接缝过渡缩短到标题栏内部，首帧使用背景占位，避免先显示清晰历史再突然变糊。继续在滚动期间连续更新，详情页译文补齐时也刷新背景采样。

同时修正背景重复记录与重新绘制造成的渲染层复用问题：正文只记录到一个绘制层，并直接从该层显示和采样。采样区域限定为标题栏大小，正文仍可以完整绘制到其外部；采样后缩到最多 320 像素宽做模糊处理。每份采样检查不透明度，空白或部分透明的帧不用于替换背景，避免清晰历史穿透到标题文字后面。

增加实际界面的副标题行框、正常和 1.6 倍字号、历史标题与模糊边界回归检查。另用真实渲染的黑白条纹测量顶部与下缘对比度及平均亮度，防止只有浅色遮罩却没有模糊，或模糊下缘未恢复清晰；反复进入详情、返回首页并切换预设后再次检查完整背景采样与滚动更新。结果和正式包校验值见本版本交付目录中的 `verification.json`。

安装包沿用原签名，可覆盖 0.5.0；项目工具只操作项目自己的 Android 模拟器。远程模型账号和用户真机未参与此次检查。
