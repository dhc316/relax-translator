# 轻松翻译使用说明

当前安装包为 `artifacts/v0.6.0/relax-translator-v0.6.0.apk`，支持 Android 8.0 及以上，可直接覆盖安装旧版。

## 预设就是独立翻译空间

左右滑动输入卡片，切换各自独立的历史、上下文和草稿。卡片保持完整宽度，左侧卡片在当前卡前方，右侧多张卡片收拢在当前卡后方；滑动时保持左高右低的层级。左卡仅覆盖约 12dp 边缘，留在输入区之外。可点击侧边露出的卡片切换。滑到最后一张卡片，或用侧栏“新建预设”进入新卡片，点击“设置这个预设”创建并编辑。

名称、补充要求、目标语言、模型、上下文和输出开关都会自动保存，无需再点保存按钮。侧栏可搜索预设和翻译，点击预设继续。旧版会话会按记录所属的预设归拢；原预设已删除但仍有历史时，升级会恢复为归档预设。

在卡片右上角点编辑，可直接“删除预设”；确认后会删除它的历史、上下文与草稿。侧栏也保留删除入口。至少保留一个预设。首页顶部只保留菜单按钮。

## 先看效果

默认使用“本地演示”。空历史首页有英文、中文辨析和日语注音示例。选择示例后发送，进入独立详情页。

“日语注音示例”展示“今天吃什么？”的中文拼音、日语假名与罗马字。英文示例提供双向注音与语法，中文辨析示例比较 a good fit、suitable、appropriate 等词的适用场景。完整注音演示以中、英、日示例为主，其他任意内容需使用真实模型。

## 添加真实模型

右上角菜单打开侧栏，进入底部设置，再点击“添加翻译模型”。

| 项目 | 内容 |
| --- | --- |
| 显示名称 | 方便辨认的名称 |
| 接口地址 | 兼容 Chat Completions 的 HTTPS 基础地址，通常以 `/v1` 结尾，也接受完整 `/chat/completions` 地址 |
| 模型 ID | 供应商提供、账号可用的模型标识 |
| API 密钥 | 自己的接口密钥，自建无需鉴权的兼容服务可留空 |
| 支持图片输入 | 按所选模型实际能力开启 |

可选 JSON 模式用于支持 `response_format` 的服务；新式长度参数用于需要 `max_completion_tokens` 的模型，其余发送 `max_tokens`。新模型最大输出长度默认 8192，旧模型设置保留。若提示回复截断，可按模型实际能力提高最大输出长度。

“测试连接”会发送一句简短文本。“保存模型”保存接口配置，并自动应用到当前预设。密钥使用 Android Keystore 加密保存在本机。修改模型配置仍需点击“保存模型”；预设内的模型选择会自动保存。

## 翻译与读音

在输入卡片输入文字，目标语言和上下文入口位于下方，都向上展开。语言菜单支持搜索和编辑常用语言；“附带图片”右边是向上展开的模型菜单。

点击“附带图片”优先打开系统照片选择器；较旧系统直接调用图库选择图片。应用会校正方向、压缩为 JPEG，最长边不超过 1800 像素。可单独发送图片，也可输入翻译范围说明。所选模型需支持图片。

发送后进入详情页。最上方的卡片依次显示可编辑原文和译文；紧接着显示双方注音与朗读入口，日语分别显示假名与罗马字。注音排在所有其他解析之前，向下滚动可阅读纠错、词汇辨析、搭配、评价及表达建议。确有错误时才出现纠错模块。

每次翻译同时向当前选择的同一个模型发起两个请求：A 只要求译文，B 要求译文与完整解析，两者使用相同的原文、图片和上下文。A 返回后即可阅读和复制译文，下方显示补充进度；B 返回后更新为完整结果，最终译文与它的注音保持一致。若 B 更快，会直接显示完整结果。两次请求只产生一条历史记录。

A 失败时继续等待 B；B 失败时保留 A 的译文并说明解析未完成。取消会停止两个请求，已得到的译文仍会保留。关闭应用后重新打开，已保存的译文可继续查看，中断的解析不会自动重新请求。每次真实翻译的接口用量按两个请求计算；“测试连接”仅发送一个简短翻译请求。

朗读使用手机系统的文字转语音服务。对应语音服务或语言包不可用时会给出提示；可在系统设置中安装所需语音。播放中可以停止。旧记录缺少的注音可点击“重新翻译”补充。

原文可直接修改后重新翻译。首页与详情页会避让系统键盘。请求中可取消；失败时保留输入和重试入口。返回历史或打开已有记录不会自动调用模型。

模型未按约定返回时，应用尝试兼容代码块、嵌套和截断数据；成功恢复译文时会提示可能缺失的解析，不将整段 JSON 当作译文。确实读不到有效译文时会提示重试。

## 独立上下文

每张预设卡片只使用自己的已完成真实翻译。支持关闭、按条数、按时间或同时限制。一次原文及其译文算一条，演示记录不参与。历史图片使用识别文字及译文，原图不重复发送。

每次最多携带约 16000 字符的完整历史片段，优先保留较近记录。单次输入最多 30000 字符，模型可能另有自己的容量限制。设置的时间控制本次发送的历史范围。

## 本地数据

首页历史卡片只显示原文与译文摘要，点击进入详情。详情底部可删除单条记录。设置中可以调整字号、管理模型、修改预设、导出历史或清空历史。

导出为 JSON，包含预设信息、原文、译文、解析及本地图片路径，不含 API 密钥，也不打包图片文件。

真实远程模型的输出质量需使用自己的接口配置验收。本次开发使用本机兼容接口测试，不借用其他项目密钥。

## 首页过渡

每张相邻卡片提前显示自己的完整草稿、图片、模型和操作区，滑动时不换成简化预览。带图和不带图预设采用统一卡片高度，添加和移除图片时平滑调整高度。标题、独立历史和语言、上下文选项跟随同一个滑动进度过渡。

历史记录可滚动到输入卡片后方，并在接近卡片时渐隐；输入卡片以浅边框与柔和阴影从共用背景中浮起。顶部背景的模糊半径从上向下线性减小，滚动中持续更新，标题和按钮保持清晰。
