# 轻松翻译 0.3.1 更新说明

本次修正两个理解偏差，沿用包名、签名及存储格式，可覆盖安装 0.3.0。

详情页顶部保留完整的原文输入与译文卡片。双方注音和朗读入口移到该卡片下方，作为第一项补充内容，之后才显示纠错、词汇、语法、评价和建议。注音仍包含日语假名及罗马字，输入上浮和键盘避让继续保留。

预设卡片改为固定的从左向右覆盖顺序：左卡在当前卡上方，当前卡在右卡上方；到最左侧时，当前卡就是最高层。滑动时层级不随距离或选中状态翻转。重叠改为较窄的边缘，保留两侧真实相邻卡片，并留出输入区内边距，避免前方卡片挡住当前输入及按钮。重叠区域由前方卡片响应点击，不会穿透到后方卡片。

界面回归直接检查实际重叠区域的点击归属、最左边界、滑动中间帧、原文和译文在注音之前、注音在其他解析之前。验证记录与截图保存在 `artifacts/v0.3.1/`。
